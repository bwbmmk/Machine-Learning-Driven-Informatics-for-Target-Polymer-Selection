# Project 1 从零开始执行指南

这套指南面向信息安全专业大二、尚未做过聚合物机器学习项目的学生。依据是根目录中的 `Project 1(1).docx`，规划日期为 2026 年 9 月 21 日。它是一套学习和执行计划，不是已完成的实验：目前没有下载并审计训练数据，也没有训练模型或产生候选材料结论。

**建议主线：先预测一种性质——玻璃化转变温度 Tg，用真实实验数据，完成结构编码、三个模型比较、候选筛选和文献核对。** 不用先学完整个机器学习专业；每学一小块，就完成一个可验收的小任务。

## 你最终要做出什么

想象一个表格：每行是一种聚合物的结构表示，以及它在实验中测得的 Tg。你把结构转换成计算机能处理的数字，让模型学习数字与 Tg 的关系，再给模型一批没有 Tg 标签的候选结构，得到预测值并挑出符合要求的候选。

```text
核实题目与数据来源
        ↓
收集有出处的聚合物结构和实验 Tg
        ↓
清洗单位、结构、重复记录与测量条件
        ↓
冻结训练集和测试集，确保同一种聚合物不跨集合
        ↓
RDKit：2D 描述符和 Morgan 指纹
        ↓
训练集内交叉验证：Dummy → Random Forest → XGBoost → LightGBM
        ↓
冻结方案 → 独立测试 → R²、RMSE、误差分析、特征解释
        ↓
同样处理候选库 → 预测 → 适用范围检查 → shortlist
        ↓
文献 benchmark 对照 → 可从头运行的 Notebook → 交付
```

你要能现场演示：输入一个格式正确、适用范围内的结构，程序输出预测 Tg、单位、模型版本、是否值得进一步核查；输入错误结构，程序给出明确错误信息，而不是偷偷输出一个数字。

## 现在就做的第一步

1. 阅读 `01`，用自己的话写出“输入是什么、标签是什么、输出是什么”。
2. 打开 `04`，复制“通用开场提示词”，再复制 T01；一并提供原始题目、`03` 和你的真实基础。
3. 完成 T01 后做 T02，确认 Python、Notebook 和库能用。不要求你今天训练模型。
4. 一开始就启动 T05 数据可行性调查。不要学了一个月才发现拿不到数据。
5. 在 `06` 里记录日期、交付文件和验收证据，再决定是否进入下一步。

第一周成功的标准：你能运行一个 Python 脚本，读一个 CSV，解释 Tg 与单体/重复单元的区别，并确认至少一条可继续调查的数据路线。不是“看完多少小时网课”。

## 工作量和设备预期

按“有大学基础编程经验，但 Python、机器学习和化学基本从零”的情况，建议预留 **12–16 周，每周约 10–12 小时，总计约 120–190 小时**。这是规划估计，不是保证；数据获取和化学映射会显著影响进度。只有每周 5 小时，就大致延长一倍。已经熟悉 Python，可跳过通过自测的部分。

先用自己的普通电脑和 CPU。初期只处理数百到数千条样本，小范围搜索参数，限制并行线程。不要先买显卡、租服务器或做网页。若内存紧张，就减少候选批量、使用稀疏指纹和更小的搜索预算。

## 三个必须诚实处理的边界

- **单体不等于聚合物重复单元。** 原题写单体 SMILES；若使用重复单元数据，要先形成明确方案并向老师确认。确认前可继续学 Python、审计数据、搭原型，但不能把变更冒充完全符合原题。
- **预测结果不等于实验结果。** 网上预测平台给的 Tg 不能充当实验标签；没有文献证据的候选应写“待验证”。
- **跑通不等于可靠。** 少量教学样本足够检查代码，不足以证明可以发现新材料。最终质量取决于数据、划分和证据，不取决于图表是否好看。

## 如果时间只有四周

前提是 Python 已能写基础脚本，而且能尽快获得合适数据。压缩为：第 1 周冻结范围和数据；第 2 周清洗、分组划分、特征及 RF；第 3 周补齐 XGBoost/LightGBM 和正式评估；第 4 周候选筛选、文献核对、Notebook。保留三模型、两类特征、R²/RMSE、候选表及文献对照；删去深度学习、网页、SHAP、大规模调参和第二性质。若前提不满足，就应缩小目标或与老师协商时间，不能用假数据填补缺口。
