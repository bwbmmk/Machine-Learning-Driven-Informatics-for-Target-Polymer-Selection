# 学习路线与每周安排

## 1 学习顺序

学习和项目并行：每次先补一个知识点，再拿真实项目做练习，最后用自己的话解释结果。建议每周约 30% 时间学习、50% 实作、20% 核查和记录。以下时数是粗略预算，遇到已经掌握的内容，通过自测即可跳过。

| 模块 | 需要掌握的内容 | 项目练习和通过标准 | 建议投入 |
|---|---|---|---|
| Python 基础 | 列表、字典、循环、函数、模块、异常、文件和路径 | 自己写一个读取 CSV、统计缺失、保存结果的脚本 | 12–18 小时 |
| 环境与 Git | 虚拟环境、pip、解释器与内核、终端、diff/commit | 重开终端仍能运行；能看懂一次修改并恢复误改 | 4–6 小时 |
| NumPy/Pandas | 矩阵 shape、索引、布尔筛选、merge、groupby、缺失值 | 清洗一个小表，保证行 ID 与特征不串行 | 8–12 小时 |
| 绘图与 Notebook | Markdown、单元格、内核、直方图、散点图 | 给图写正确标题/单位；重启后 Run All 成功 | 4–6 小时 |
| 最低限度化学 | 官能团、化学键、单体/重复单元、均聚/共聚、Tg/Tm | 看懂 5–10 个简单结构，解释为什么不能混用表示 | 8–12 小时 |
| 数据证据 | 实验/模拟/预测、单位、来源、测量条件、重复记录 | 对 20 条记录逐条给出处和处理决定 | 6–10 小时 |
| 数学与统计 | 均值/方差、相关、向量矩阵、训练/测试、误差 | 手算 3 个样本的 MAE/RMSE，解释 R² 可为负 | 5–8 小时 |
| 监督学习 | X/y、回归、欠拟合/过拟合、交叉验证、基线、泄漏 | 能说明为什么不能用测试集选参数 | 8–12 小时 |
| RDKit | SMILES 解析、合法性、描述符、Morgan、Tanimoto | 无效结构不崩溃；相同输入生成相同长度特征 | 8–12 小时 |
| 树模型与调参 | 决策树、RF、boosting、深度、叶子、学习率 | 在同一划分上完成三模型，解释控制复杂度的方法 | 8–12 小时 |
| 筛选与报告 | 阈值、适用范围、文献核对、可复现性 | 输出有证据和限制的 shortlist；解释一个失败案例 | 6–10 小时 |

这些知识学习约 77–118 小时，和做项目的时间会重叠，不要把表中时数再机械加到全部项目工期上。数据整理、调试和最终交付还要留机动时间。

## 2 暂时不需要学的内容

暂缓 PyTorch、Transformer、图神经网络、强化学习、分子动力学、量子化学、复杂化学合成、网页全栈和云部署。也不必从证明反向传播或推导全部 boosting 公式开始。先能解释输入、标签、划分、评价和预测边界，再补理论深度。

信息安全基础可迁移到这里：输入校验对应 SMILES 和表格校验；审计日志对应数据来源和清洗记录；可复现构建对应环境和运行配置；“训练集偷看测试信息”可以理解为评估边界失效。但项目主体仍然是材料预测，别把它改成安全攻防项目。

## 3 最低限度概念词典

| 词 | 本项目中是什么意思 |
|---|---|
| Tg | 玻璃化转变温度，反映非晶部分链段运动发生明显变化的温度区间；不等于熔点 Tm |
| SMILES | 用文本表达分子图结构的方式；字符串不是标签，也不是完整材料制备说明 |
| 重复单元 | 聚合物链重复出现的结构片段，连接点常用 `*` 表示 |
| Descriptor | 人为定义的数值特征，如环数、极性表面积；有限片段的质量不等于整个聚合物分子量 |
| Fingerprint | 把局部子结构映射为位或计数；Morgan 位可能发生哈希碰撞 |
| X / y | X 是输入特征矩阵，y 是实验 Tg；行顺序必须严格对应 |
| Regression | 预测连续数值，本项目不是分类，不用 accuracy 当主要指标 |
| Baseline | 简单参照，如所有样本都预测训练集平均 Tg |
| Overfitting | 把训练数据细节学得很好，却不能推广到未见材料 |
| Group split | 同一种聚合物的多次测量和重复表示始终放在同一组 |
| Applicability domain | 模型所覆盖的结构和数据范围；陌生结构的预测需要更谨慎 |
| Benchmark | 有明确来源、条件和可比性的对照对象，不是从网上抄一个“标准值” |

数学只先掌握这些：`MAE = mean(abs(y - pred))`；`RMSE = sqrt(mean((y - pred)^2))`；`R² = 1 - sum((y-pred)^2)/sum((y-mean(y))^2)`。R² 在目标有变化时使用，目标恒定或样本太少时可能没有意义；在测试集上小于 0 表示比用该测试集均值作常数参照还差。Dummy 则必须只从训练集学习均值，二者不要混为一谈。

## 5 第一周每天怎么做

- 第 1 天，约 1.5 小时：读题目与 `01`，填项目 brief，整理给老师的问题。
- 第 2 天，约 2 小时：创建独立环境，确认解释器、Notebook 内核、库导入；保存版本。
- 第 3 天，约 1.5 小时：写列表、循环、函数；读取一个 CSV，打印列和行数。
- 第 4 天，约 1.5 小时：做缺失值、重复行和单位转换练习。教学数值必须标明用途。
- 第 5 天，约 1.5 小时：学单体/重复单元、Tg/Tm，画几个简单分子。
- 第 6 天，约 2 小时：调查两个数据入口，保存来源信息，抽看结构、标签和单位。
- 第 7 天，约 1 小时：不让 AI 代答，解释本周代码；更新进度，写下一项任务。

## 6 怎么判断自己是真的会了

每次 AI 交付后，自己做三件事：运行一次；改一个小输入再运行；口头解释一张图或一个函数。至少能回答：“这个文件从哪来”“为什么删这行”“这个指标怎么得到”“下一步读什么文件”。

出现错误时，给 AI 完整 traceback、运行命令、工作目录、Python 路径、版本和最小输入。不要只发“报错了”，也不要让它直接重写整个项目。

学习资料入口见 `05`。只读与当前任务有关的章节；例如做 T03 时无需读完 scikit-learn 用户手册。
