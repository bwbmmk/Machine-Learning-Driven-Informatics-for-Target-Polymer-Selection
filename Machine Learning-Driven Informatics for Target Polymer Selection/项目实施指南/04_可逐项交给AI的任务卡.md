# 可逐项交给 AI 的任务卡

下面是 24 张连续任务卡。每张建议拆成一次或几次对话，按验收结果推进，不要求一次生成全部项目。T05 数据调查要尽早开始；T03/T04 的基础学习可在等待来源信息时继续。

## 每次先复制这段通用提示词

```text
我是信息安全专业大二学生，正在从零做 Project 1 聚合物性质预测项目。
请先阅读我提供的原题、项目实施指南/03_数据与实现规范.md、
docs/project_brief.md（若已有）及上一份 handoff。只执行本次任务卡。

先检查现有文件，说明本次输入和要修改的文件，不要重写已完成的模块。
请用中文解释，代码中的函数/变量/文件名保持英文。
把工作拆成我能跟得上的小步骤，解释每条运行命令的作用。
只实现任务所需内容；不要擅自增加网页、深度学习或改预测目标。

不能编造数据、来源、论文、运行记录、指标和实验结论。
教学假数据必须放独立 demo 区，标记 synthetic，不得进入正式结果。
缺少输入时给出具体阻塞点和可继续做的事情，不能用随机数冒充实验标签。
不改变单体/重复单元约定；不使用测试集做选择；保留数据来源和清洗记录。
如果新证据要求修改规范，先解释原因并写决策记录，保持下游兼容。

结束时给出：修改文件、准确运行命令、真实运行结果（未运行就明说）、
验收逐项结果、已知限制、下一任务需要的输入。
写 handoffs/Txx.md，并根据证据更新进度，不要把“文件已生成”当成验收通过。
最后问我 3 个理解检查题，帮助我自己解释本次实现。

下面是本次任务卡：
```

你需要一并提供实际文件。其他 AI 不会自动知道本次对话和你本机的目录。不能访问文件的 AI 应输出可保存的完整内容与命令，并注明没有本地执行。

## T01 冻结项目范围

- **依赖/输入**：原题、`01`、你的每周时间、已知截止时间；未知项可以先写未知。
- **学习目标**：分清输入、输出、标签、性质与评估。
- **执行指令**：创建 `docs/project_brief.md`，采用单目标 Tg 主线；分别列出单体路线和重复单元路线的可行性及待确认事项。写明首版不做共聚配方/深度学习/网站，除非题目后来明确要求。建立 `docs/decisions.md`，记录已确认和暂定事项。
- **输出**：brief、决策记录、给老师的五项问题。
- **验收**：能说清训练一行代表什么；实验标签不能来自预测平台；输入表示是否获准有明确状态。尚未获准时任务可作为“临时范围已写明”完成，但 T06 正式定稿受此阻塞。

## T02 建好独立环境

- **依赖/输入**：T01、Windows 电脑、已有 Python 情况。
- **学习目标**：理解解释器、包和 Notebook 内核是如何对应的。
- **执行指令**：检查已有环境再选择安装方案。建立项目专用环境与必要依赖、`.gitignore`、`scripts/check_environment.py`，打印 Python 路径和各库版本，并用一个简单结构检查 RDKit。确认 RF/XGBoost/LightGBM 可导入且能运行极小教学回归。教学样本仅用于环境冒烟检查。
- **输出**：环境说明、依赖版本、检查脚本、运行日志。
- **验收**：新终端及 Notebook 中均使用目标解释器；`pip check` 无依赖错误或有明确处置；三模型和 RDKit 可运行。不要求训练正式模型。

## T03 Python 和表格最小练习

- **依赖/输入**：T02。
- **学习目标**：函数、DataFrame、文件路径、缺失值、错误信息。
- **执行指令**：在独立 `demo/` 下创建小型 CSV 练习，包含重复行、缺失值和不同单位。可使用明确标记的人工教学数据，不提供虚假的真实聚合物 Tg。带我编写读入、筛选、单位转换、统计与导出函数，并用 `record_id` 保持对齐。
- **输出**：练习脚本、教学输入、教学输出、中文说明。
- **验收**：我能修改输入再运行，解释每个函数；教学数据不能被正式 pipeline 默认读取。

## T04 学会读取简单结构

- **依赖/输入**：T02、`01` 表示说明。
- **学习目标**：单体、重复单元、官能团、SMILES、Tg/Tm。
- **执行指令**：建立化学入门笔记，选择 5–10 个可核查的简单结构，画结构图并解释 SMILES 符号。展示单体和对应重复单元的区别，加入无效 SMILES 检查。讲解 Tg 不是熔点、结构信息不能唯一决定所有测量条件。
- **输出**：`docs/chemistry_basics.md`、小练习和结构图。
- **验收**：我能解释 `C=C` 与 `[*]CC[*]`；程序识别无效结构；不包含未核实的性质数值。

## T05 核查数据源可行性

- **依赖/输入**：T01、`05`；可在 T02–T04 期间开始。
- **学习目标**：来源、实验标签、可用性与使用条件。
- **执行指令**：调查至少两个候选来源，优先已关联论文的公开数据。先看元数据与少量样本，不要大规模爬虫。逐项核实能否下载、字段、单位、实验/模拟身份、表示、独立聚合物数、来源、使用条款。对 PoPE 入口未知和 Polymer Genome 非实验数据下载库的情况写明。提出主来源与备用方案。
- **输出**：`data/sources.csv`、`docs/data_feasibility.md`、可获得的小样本和来源说明。
- **验收**：至少一条路线实际拿到可读样本并确认核心字段，或清楚报告数据阻塞；不能只列网站名字就声称数据已获得。不可获取时联系老师索取允许使用的文件，基础学习继续。

## T06 冻结数据字典与表示策略

- **依赖/输入**：T04、T05 样本、T01 的输入方案确认。
- **学习目标**：原始数据与建模数据为何不同。
- **执行指令**：按 `03` 映射原始列，明确单位、记录粒度、聚合物身份、单体对应关系及 `*` 处理。创建表示规范和机器可读配置。若输入与原题不一致且未获确认，标为临时实验，不得冻结成最终提交方案。
- **输出**：`docs/data_dictionary.md`、`docs/representation_policy.md`、`configs/project.json`。
- **验收**：人工核对约 10 个结构；每个列有含义和缺失策略；结构转换不是字符串猜测；训练和候选库将采用同一处理。

## T07 收集并逐条审计样本

- **依赖/输入**：T05–T06。
- **学习目标**：从论文或表格到可追溯记录。
- **执行指令**：保存原始文件、哈希和访问日期，建立 `src/data.py` 的数据导入函数。抽查至少 20 条，记录原表位置、结构、实验数值、单位和条件，额外审计异常类型；区分实测、模拟、机器学习预测和未知。
- **输出**：`data/raw/`、来源表、`data/interim/audit_sample.csv`、审计说明。
- **验收**：抽查记录能回到原始证据；不把论文模型输出当实测；无法确认的行进入隔离区。

## T08 实现可重跑清洗

- **依赖/输入**：T06–T07。
- **学习目标**：缺失、重复、单位、异常和统计口径。
- **执行指令**：实现数据清洗；按固定规则汇总可比重复实验，保留测量离散信息；给所有排除或隔离行理由；生成数据卡和基本分布图。不要为提高分数删真实极端值。
- **输出**：`data/processed/polymer_tg.csv`、`reports/cleaning_log.csv`、`docs/data_card.md`、分布图。
- **验收**：数量变化可对账；正式数据关键列齐全；K/°C 转换正确；实验标签与来源保留；同一输入重跑结果一致。

## T09 冻结分组划分

- **依赖/输入**：T08 和聚合物身份核对。
- **学习目标**：为什么重复材料不能分到训练和测试两边。
- **执行指令**：建立 `src/split.py`，按 `group_id` 生成开发/测试划分和开发集内 CV 折。固定随机种子、比例和测试用途。检查等价重复单元表示，不能只按原始 SMILES 去重。
- **输出**：`artifacts/splits.csv`、`docs/evaluation_protocol.md`、重复与组交叉检查报告。
- **验收**：没有组跨集合或 CV 折；每条记录只分配一次；CV 折数合理；协议规定正式模型冻结后才进行最终测试。只查看规模和预定诊断，不反复换种子刷成绩。

## T10 生成 2D 描述符

- **依赖/输入**：T06、T08–T09。
- **学习目标**：一个结构如何变成数字向量。
- **执行指令**：在 `src/features.py` 实现固定描述符列表、异常日志、列名和行 ID 保存。对含 `*` 的输入执行既定策略并验证语义；片段质量不能标成聚合物分子量。插补和列筛选放入训练内部预处理。
- **输出**：描述符矩阵、ID 清单、特征定义、失败表。
- **验收**：特征和标签 ID 对齐；无静默行丢失；异常值可解释；同一结构重复运行一致；无目标值混入特征。

## T11 生成 Morgan 指纹

- **依赖/输入**：T06、T08–T09、T10 的公共接口。
- **学习目标**：半径、位数和局部子结构含义。
- **执行指令**：扩展同一特征模块，使用 Morgan generator，记录半径、位数、手性和位/计数选项。输出矩阵、ID 和 metadata，提供两个结构相似度的小例子。
- **输出**：指纹矩阵、配置、示例解释。
- **验收**：每行长度固定、ID 对齐；bit 指纹只含 0/1；相同输入一致；不把某一个 bit 无依据命名为唯一化学基团。

## T12 建立 Dummy 基线与统一评价

- **依赖/输入**：T09–T11。
- **学习目标**：模型为什么必须比一个简单参照更好。
- **执行指令**：实现训练折内均值 Dummy、统一 RMSE/R²/MAE 计算、CV 结果格式。先使用开发集 CV，不打开最终测试评估。用可手算的小数组核对指标函数。
- **输出**：`src/evaluate.py`、基线 CV 表、指标检查。
- **验收**：Dummy 不使用验证/测试均值拟合；指标公式与单位正确；各折结果和 ID 可追溯。

## T13 用 Random Forest 跑通主线

- **依赖/输入**：T12。
- **学习目标**：训练、预测、过拟合、模型保存。
- **执行指令**：建立 `src/train.py`，对描述符和 Morgan 分别训练 RF，按固定 CV 记录指标。先保守配置，不大规模调参；保存一个开发用模型，做保存/加载一致性检查。
- **输出**：两组 RF CV 实验、预测明细、开发模型、说明。
- **验收**：原始表到预测值的闭环可重跑；不碰最终测试选参；对比 Dummy；结果差也如实保留。

## T14 补齐 XGBoost 和 LightGBM

- **依赖/输入**：T13。
- **学习目标**：RF 和 boosting 的基本差异。
- **执行指令**：增加两个库的 sklearn 接口，沿用共同划分、特征和评价。完成三模型×两类特征的六组 CV。限制线程，记录运行时间和参数。若安装失败，解决环境或明确记录缺项，不能用另一个模型更名冒充。
- **输出**：六组合 CV 表、每折指标、训练配置。
- **验收**：确实调用三种模型；比较条件一致；报告训练/验证差异；不凭某一个最好折决定赢家。

## T15 小预算选择与冻结方案

- **依赖/输入**：T14。
- **学习目标**：超参数和模型选择偏差。
- **执行指令**：先写搜索预算和主指标，再在开发集 CV 内小范围调参；插补等必须在每折训练部分 fit。按平均 CV RMSE 选特征与模型，写冻结配置及理由。不要做大网格或用测试集 early stopping。
- **输出**：`reports/experiments.csv`、冻结配置、`docs/model_selection.md`。
- **验收**：所有尝试可追溯，最终选择依据预先约定；没有用测试结果做决策；提升不明显时保留更简单方案并说明。

## T16 正式独立测试与误差分析

- **依赖/输入**：T15 已冻结。
- **学习目标**：验证和最终测试的角色不同。
- **执行指令**：在全部开发集重训冻结方案，对测试集进行正式评估；输出 R²、RMSE、MAE、逐行预测、parity 图和残差图。按材料类别/标签区间作描述性误差分析，小分组注明样本量。诊断不作为再次挑模型的借口。
- **输出**：`reports/tables/test_predictions.csv`、最终指标表、图、误差讨论。
- **验收**：指标能从明细重算；图单位正确；模型/数据/配置对应；成绩差不隐藏；若发现程序错误需修正，记录旧结果作废原因，不声称多次选择后测试仍完全独立。

## T17 做特征重要性解释

- **依赖/输入**：T15、训练内部验证预测；可与 T16 后续整理衔接。
- **学习目标**：预测关联不是化学因果。
- **执行指令**：在开发集内的验证折上做 permutation importance，重复计算并报告波动。给出描述符模型解释；如果最佳模型是指纹模型，说明两者关系并提供指纹位重要性及碰撞限制。需要化学解释时找可核实依据，不能从重要性直接断言“导致 Tg 上升”。
- **输出**：重要性表图、`docs/interpretation.md`。
- **验收**：说明解释的是哪个模型、特征和数据分区；不使用重要性结果回头筛测试特征；报告负重要性或不稳定现象而不是隐藏。

## T18 建立模型适用范围提示

- **依赖/输入**：T11、T15 的开发集 CV 明细。
- **学习目标**：相似材料和陌生材料的预测风险不同。
- **执行指令**：计算验证样本到对应训练折的最大 Tanimoto 相似度，比较相似度与误差；建立候选对开发训练集的相似度和描述符超范围提示。只有证据足够才预设阈值，否则保留连续指标。
- **输出**：`docs/applicability_domain.md`、相似度诊断、可复用函数。
- **验收**：不拿样本与自身算最近邻；不把相似度/模型分歧叫置信概率；阈值来源和局限明确；不借最终测试调阈值。

## T19 构建候选库与锁定筛选规则

- **依赖/输入**：T06、T18、应用约束。
- **学习目标**：无标签候选、已知材料和 benchmark 的区别。
- **执行指令**：整理有出处的候选，起步控制在约 100–1000 条，按与训练相同规则校验；排查训练/测试等价结构重叠；确认候选确实属于输入表示范围。若只有重复单元结构库而项目严格用单体，不得直接替代。锁定目标阈值、范围风险处理和排名规则。
- **输出**：`data/candidates/candidates.csv`、来源及拒绝表、筛选配置。
- **验收**：每个候选可追溯；重复与适用范围有记录；规则在看最终排名前确定；不知道性质的候选没有捏造 Tg。

## T20 执行虚拟筛选

- **依赖/输入**：T16 评估通过或已明确有限效力、T19。
- **学习目标**：模型输出如何成为可审查的候选列表。
- **执行指令**：实现 `src/screen.py`，加载模型整体和 metadata，对候选使用相同预处理与特征。输出全部预测、满足约束状态、范围提示和 Top 10–20。未知文献字段留空，后续补充；没有合格候选时正常输出空 shortlist。
- **输出**：`reports/tables/candidate_predictions.csv`、`shortlist.csv`、拒绝理由。
- **验收**：排名能追溯到规则和预测；K/°C 对应正确；不混入已知训练材料充新候选；不宣称已证实可合成。

## T21 补齐文献 benchmark 对照

- **依赖/输入**：T19–T20；文献集合最好在模型冻结前预先锁定。
- **学习目标**：同材料验证与相近材料参照的证据强度不同。
- **执行指令**：核查 5–10 个文献对照对象（数量为建议），记录原始单位、实验方法、条件、精确表/页位置。与训练源做重叠检查。对 shortlist 中有实测依据的材料核对身份；无实测候选写待验证，可给相近材料参照但不能算它的预测误差。若对照曾参与训练，明确是回顾性演示。
- **输出**：`data/benchmark/literature.csv`、`reports/tables/shortlist_literature.csv`、文献讨论。
- **验收**：引用真实且逐行可核查；实测与预测区分；只有可比同材料计算误差；无来源的数值不进入表；不能用“未找到”假装已经完成了文献对照要求。

## T22 组织最终 Notebook 和报告

- **依赖/输入**：T08–T21 的真实成果。
- **学习目标**：把代码结果讲成可检查的研究过程。
- **执行指令**：创建 `notebooks/project1.ipynb`，顺序为问题、数据来源、结构策略、清洗、划分、两类特征、基线与三模型、冻结选择、最终测试、重要性、筛选、文献对照、局限、复现信息和引用。调用 `src` 而不是重写逻辑，制作 `reports/final_report.md`。
- **输出**：Notebook、报告、图表索引。
- **验收**：没有写死虚假指标；图表来自实际运行；每个章节有中文解释；文献来源与候选表对应；所有已知缺项明确列出。

## T23 从头复现和关键检查

- **依赖/输入**：T22。
- **学习目标**：别人拿到文件后也能运行。
