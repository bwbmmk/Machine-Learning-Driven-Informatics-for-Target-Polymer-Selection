## 4 实验记录模板

每一条实验至少记录：`experiment_id, timestamp, git_commit_or_code_hash, data_hash, split_hash, representation, feature_set, model_name, params, seed, n_train_groups, n_val_groups, fold, rmse_k, mae_k, r2, runtime_seconds, status, notes`。

开发阶段记录每折和汇总；最终测试另表保存，并写明选择方案的冻结日期。不要把自己最喜欢的一次结果单独截出来而丢掉其他尝试。

## 6 最终交付清单

### 原题成果

- [ ] Python 完整流程，从数据到筛选可按说明运行。
- [ ] 实验性质与结构数据有明确来源、单位及身份。
- [ ] 输入表示符合确认后的题目范围。
- [ ] RDKit 的 2D 描述符和 Morgan 指纹均已实现。
- [ ] Random Forest、XGBoost、LightGBM 都有真实评估。
- [ ] R²、RMSE 和特征重要性分析完整。
- [ ] Jupyter Notebook 有中文说明且重启内核后 Run All 成功。
- [ ] 候选矩阵包含筛选规则、预测值和适用范围说明。
- [ ] 候选与文献 benchmark 有真实、可比性明确的对照。

### 正确性与复现

- [ ] 原始文件保留；清洗日志能解释行数变化。
- [ ] 实验标签与模拟/预测标签分开。
- [ ] 同材料或等价结构没有跨训练/测试及 CV 折。
- [ ] 没有把 Tg、来源编号、名称或 benchmark 数值当结构特征。
- [ ] 模型选择和预处理没有使用测试集信息。
- [ ] 指标能从保存的真实/预测明细重算。
- [ ] 模型加载后预测一致；候选预处理与训练一致。
- [ ] 测试结果、部署模型与数据版本对应清楚。
- [ ] 无效输入和空候选有正常处理。
- [ ] README 给出环境、数据获取、命令、输出位置和预计计算规模。
- [ ] 许可不明的数据没有擅自公开再分发。

### 表达与答辩

- [ ] 结论明确数据范围，没有把预测说成实验确认。
- [ ] 没有把模型分歧称作已校准的置信区间。
- [ ] 没有把重要性图解释成化学因果证明。
- [ ] 没有把训练集中见过的材料称为新发现。
- [ ] 文献单位、条件、重叠和相近材料关系写明。
- [ ] 模型不优于基线或候选证据不足时，结论相应收缩。

## 7 答辩时你应能回答

1. 你的模型输入到底是单体还是重复单元？为什么这样选择？
2. Tg 是什么，为什么不能拿熔点当标签？
3. 每一行数据从哪里来，实验和预测如何区分？
4. 为什么同一聚合物不能同时出现在训练集和测试集？
5. 描述符和 Morgan 分别保留了什么信息，丢失了什么信息？
6. 为什么设置 Dummy？三种模型如何公平比较？
7. 你的 RMSE 对实际筛选意味着什么？R² 可不可以小于零？
8. 特征重要性可以说明什么，不能说明什么？
9. 某候选为何入选，证据够不够，是否在模型适用范围内？
10. 文献对照是否独立？相近材料的实验值为何不能充当候选真值？
11. 哪些情况模型失败？下一步更值得补数据还是换模型？
12. 如果换一台电脑，你怎样复现结果？
