# 历史归档

这里保留旧版本，避免它们与当前练习主线混淆。继续学习请打开 [完整练习包](../python_handson_pack/README.md)。

| 原位置 | 现位置 | 内容 |
|---|---|---|
| 根目录同名长标题文件夹 | `github_upload/` | 早期 GitHub 上传的整份副本，内部结构原样保留 |
| 根目录 `p01_read/`–`p05_clean/`、`e01_import/`–`e04_security/`、`data/` | `loose_lessons/` | 早期散放且不完整的题目与配套数据 |
| 根目录 `python_practice/` | `python_practice/` | 最早的第一题骨架和教学记录 |

没有删除或覆盖这些旧代码。`github_upload/` 和 `loose_lessons/` 是历史快照，文中的路径、链接和命令可能指向当时的布局，不作为现在的执行入口。根目录遗留的 Python 缓存也随散放题目移入归档，仍被 Git 忽略。

如需迁移自己在旧题目里写过的实现，先对照新关卡的函数接口与测试，再手动迁入 `python_handson_pack/lessons/`，不要整目录覆盖新包。

另外，原题和 Git 图移到了 `../references/`，ZIP 移到了 `../releases/`，原 `_learning_pack_build/build_pack.py` 移到了 `../tools/build_pack.py`。
