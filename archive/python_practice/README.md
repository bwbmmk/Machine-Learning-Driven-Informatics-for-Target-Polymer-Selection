## 数据含义

所有名称与温度均为人为构造，`is_synthetic` 均为 true。SMILES 字符串只作为字段和解析练习，不表示相应虚构名称真的是某种聚合物，也不表示这些温度是对应分子的性质。禁止将此文件用作真实材料实验数据或模型效果证据。

| 字段 | 本练习含义 |
|---|---|
| record_id | 记录 ID；EX02 故意出现两次 |
| name | 虚构名称，仅用于查询 |
| smiles | 示例字符串；前期不检查化学合法性 |
| tg_value | 人为温度，混有数字、数值字符串、空白等 |
| tg_unit | C 或 K，混有未知单位 |
| is_synthetic | 固定 true，导出时保留 |

## 第一题

补写 `load_records(path)`，返回读取的列表；补写 `main()`，调用函数、打印记录数量和前三条记录的 ID、名称、原始温度和单位。

在项目根目录：

```powershell
py archive/python_practice/01_read_records.py
```

或进入本目录后：

```powershell
py 01_read_records.py
```

如果本机通常使用 `python`，可替换 `py`。无需先装第三方包。骨架尚未完成时抛出 `NotImplementedError` 是预期行为，不是环境故障。

第一题完成后应读到 12 条，前三个 ID 为 EX01、EX02、EX03。不要一开始清洗或去重，否则与第一题要求不符。
