## 遇到这些词怎么理解

“回归”是预测一个数；“基线”是简单的比较办法；“训练”是让模型从例子学习；“测试集”是留下来检查的例子；RMSE 是误差大小的一种算法，同样的测试数据上一般越小表示预测更接近实际值。
