# E04 统计登录失败次数，检查文件是否变化（选做）

这是与你的信息安全专业更接近的扩展。用虚构日志统计一段时间里每个用户登录失败几次，再给文件算一个便于比较的摘要。

先完成：P08；选做，标准库。本关主要练：datetime、字典计数、二进制读文件、hashlib。

第一次做题，先读 [怎么开始](../../START_HERE.md)。下面所有命令都在有 `check.py` 的 `python_handson_pack/` 目录运行。

## 要做成什么样

时间范围内：小明失败两次、小红成功一次，那么结果只含 `{"小明": 2}`。
范围外的事件不计入，范围两端时刻的事件计入。
sha256_file 返回一串 64 个小写十六进制字符；同一文件内容不变时，重复计算应相同。

## 打开哪里，按什么顺序写

先打开 `lessons/e04_security/task.py`。下面每一步都可以单独当作一次小练习；不要求一次写完整关。

1. **先看一条日志**：打开 data/synthetic_events.json，timestamp 是时间，user_id 是用户，success 表示是否成功。
2. **先比较时间**：把日志时间以及起止时间读成 datetime。要求都有时区，起点不能晚于终点。
3. **再做计数**：在 failed_counts 中，只对范围内 success=False 的事件按用户加一。
4. **另写文件摘要函数**：sha256_file 以二进制分块读文件，不断更新哈希，最后返回摘要。用自己新建的测试文本改一字再比较，不改原始资料。
5. **可再添加命令入口**：仿照 P08，让你的工具能从终端接收文件地址和时间范围。

## 遇到这些词怎么理解

“时区”说明同一个钟点属于哪个地区的时间；“哈希摘要”像用于比对内容的短指纹，不是加密，也不能仅凭它证明文件来源。

## 写完后核对的具体规则

这部分保留准确的函数名、返回格式和特殊情况，方便检查，也方便其他 AI 辅导。第一次不用全背下来；写到哪个函数，再对照哪条。

failed_counts(events,start,end) -> user_id到失败次数的字典。事件字段 timestamp（带时区ISO字符串）、user_id、success（bool）。start/end也是带时区ISO字符串；使用 datetime 进行比较，start>end或缺时区抛 ValueError。成功用户不列入结果，空结果 {}。
sha256_file(path) -> 64字符小写十六进制摘要；文件不存在保留 FileNotFoundError。请分块读取，不要求一次把整个文件放内存。
只用本地虚构日志，不需要网络扫描或任何真实账号。
