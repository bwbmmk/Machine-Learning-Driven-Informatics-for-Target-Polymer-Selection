# P01：卡在哪一步，就看哪一段

## 不知道读取函数要干什么

输入是文件地址，输出是文件里的资料。顺序只有三个动作：打开文件 → 读成 Python 对象 → return 结果。读取函数里先不要 print；显示结果是 main 的工作。

## 不知道要查哪些写法

- 查 `with open`：如何以只读方式打开 UTF-8 文本文件，用完后自动关闭。
- 查 `json.load`：它接收已经打开的文件对象，不是文件地址。`json.loads` 接收文字字符串，本题先用前者。
- 读出结果后，用 `return` 把它交出去。如果没有 return，调用者通常只能得到 None。

每次只查一个点，然后回 task.py 写几行。不要为了这一题读完整份 JSON 文档。

## 不知道怎样取前几条

先用普通数字理解：列表 `[10, 20, 30, 40]` 的前两条是 `[10, 20]`。可以查“Python 列表切片”。

题目还规定：n=0 返回空列表；n 比总数大就返回全部；n<0 报 ValueError。负数的切片原本有别的含义，所以需要你在切片前单独检查。

## 不知道 main 写什么

先用 DATA_PATH 调用读取函数，把结果存入变量；用 len 得到条数；把列表交给预览函数；再循环显示每条记录的 record_id、name、tg_value、tg_unit。

一开始可以先只显示总数，成功以后再加前 3 条。展示格式由你决定，不要求和例子每个空格都一样。
