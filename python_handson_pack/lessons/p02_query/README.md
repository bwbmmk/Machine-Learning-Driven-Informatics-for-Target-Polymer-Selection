# P02 按编号或名字查资料

像查通讯录：输入编号，找出对应资料；输入名字的一部分，找出所有符合的资料。一个编号可能出现多次，所以不能找到第一条就停。

## 要做成什么样

例如输入：

```python
rows = [
    {"record_id": "A", "name": "Red apple"},
    {"record_id": "B", "name": "Banana"},
    {"record_id": "A", "name": "Green apple"},
]
```

`find_by_id(rows, "A")` 应返回第 1、3 条组成的列表；查 `"Z"` 应返回 `[]`。
`search_by_name(rows, " APPLE ")` 也应找到第 1、3 条，因为忽略关键词两端空格和英文大小写。

## 打开哪里，按什么顺序写

先打开 `lessons/p02_query/task.py`。下面每一步都可以单独当作一次小练习；不要求一次写完整关。

1. **只写编号查询**：在 `find_by_id` 中准备一个空结果列表，逐条比较编号，把所有符合的记录收集起来，循环结束后返回。
2. **先用三条记录检查**：用上面的 A、B、A 例子检查：返回两条；换成 Z 检查：返回空列表。
3. **再写名字查询**：先整理关键词两端空格和大小写，再逐条判断名字里有没有它。没有名字或名字不是字符串的记录就跳过。空关键词直接返回空列表。
4. **接上文件读取**：在 `variations.py` 写少量调用代码，使用 P01 的 load_records 读取教学文件，再查询 EX02。它应找到两条。

## 遇到这些词怎么理解

“匹配”就是符合查找条件；“子串”就是一段文字，例如 apple 在 Green apple 中；“不改变输入”就是不要删除或修改传进来的原记录。

## 写完后核对的具体规则

这部分保留准确的函数名、返回格式和特殊情况，方便检查，也方便其他 AI 辅导。第一次不用全背下来；写到哪个函数，再对照哪条。

输入 records 为字典列表。find_by_id 做原始 ID 精确匹配，返回全部命中，顺序与输入一致。
search_by_name 对关键词去空格，使用不区分大小写的子串匹配；空关键词返回 []。
name 缺失、null 或非字符串时当作不可匹配。两个函数都不改变输入。
