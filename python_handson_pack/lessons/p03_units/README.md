资料里有的温度用 C（摄氏度），有的用 K（开尔文）。要比较它们，先统一成 K。你主要在练数字转换和错误处理。

## 要做成什么样

先记两条换算关系：`K = C + 273.15`，`C = K - 273.15`。

| 调用 | 应得到的结果 |
|---|---|
| `to_kelvin(25, "C")` | 298.15 |
| `to_kelvin(310, "K")` | 310.0 |
| `to_kelvin("-20", " c ")` | 253.15 |
| `kelvin_to_celsius(298.15)` | 约 25.0 |
| `to_kelvin("warm", "C")` | 报 ValueError，意思是输入不是可用的数值 |

这里按题目约定，只接受大于 0 的 K；0 摄氏度可以接受。

## 遇到这些词怎么理解

“有限数”指普通数值，不包括无穷大和 NaN（不是有效数字）。`ValueError` 表示函数收到了不合要求的值。

## 写完后核对的具体规则

这部分保留准确的函数名、返回格式和特殊情况，方便检查，也方便其他 AI 辅导。第一次不用全背下来；写到哪个函数，再对照哪条。

to_kelvin(value, unit) 接受 int/float 或数值字符串（bool 除外），unit 必须为字符串 C/K，忽略两端空格和大小写。返回 float；结果必须 >0 且有限；不满足约定一律 ValueError。
kelvin_to_celsius(value) 使用相同的数值检查，要求输入 K>0。
