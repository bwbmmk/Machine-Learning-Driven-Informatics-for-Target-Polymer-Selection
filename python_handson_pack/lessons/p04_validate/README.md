# P04 逐条检查资料，写出哪里有问题

想象你在检查一张报名表：有的人没填编号，有的人把温度写成了 warm。程序要指出哪条有问题，以及是什么问题。

先完成：P03。本关主要练：调用已有函数、try/except、错误信息列表、enumerate。

第一次做题，先读 [怎么开始](../../START_HERE.md)。下面所有命令都在有 `check.py` 的 `python_handson_pack/` 目录运行。

## 要做成什么样

`validate_record({"record_id": "A", "tg_value": 25, "tg_unit": "C"})` 应返回 `[]`，表示没有发现本题要求检查的问题。

如果编号是空字符串、温度是 `"warm"`，应该同时说明编号和温度的问题。
整批检查的一条结果可以是：

```python
{"row_number": 1, "record_id": "A", "ok": True, "errors": []}
```

它表示“输入中的第 1 条，编号 A，通过检查，没有错误”。

## 打开哪里，按什么顺序写

先打开 `lessons/p04_validate/task.py`。下面每一步都可以单独当作一次小练习；不要求一次写完整关。

1. **检查一条资料的类型**：先写 validate_record。如果拿到的不是字典，例如数字 3，返回一条错误说明。
2. **检查编号和温度**：编号必须是非空文字；温度调用你在 P03 写的 to_kelvin。温度转换报 ValueError 时，把原因放进错误列表。编号错了也继续检查温度。
3. **检查多条资料**：在 check_records 中逐条调用 validate_record，按从 1 开始的顺序编号，为每条建立结果字典。
4. **检查教学文件**：读入 12 条资料后检查，应该有 5 条不通过。本题只看编号和温度，不检查名字和结构字符串。

## 先检查一小步

先让单条合法资料返回 []；再让单条错误资料返回原因。等这两种都能解释，再做整批处理。

都写完后，再运行整关检查：


如果电脑使用 `python`，把命令里的 `py` 换成 `python`。这条命令会运行一组检查；只完成一小步时，其他检查失败是正常的。先看报错最后几行，只解决当前这个问题。

## 遇到这些词怎么理解

“校验”就是按规定检查；“报告”就是程序整理出的结果；ok 为 True 表示本题检查通过，不代表这条资料在所有方面都正确。

## 写完后核对的具体规则

这部分保留准确的函数名、返回格式和特殊情况，方便检查，也方便其他 AI 辅导。第一次不用全背下来；写到哪个函数，再对照哪条。

validate_record(row) 返回错误字符串列表，合法时 []。非字典只需一条说明；ID 必须是去空格后非空的字符串，校验不改原 ID。温度规则复用 P03。
check_records(records) 返回列表，每项恰含 row_number（从1起）、record_id（非字典或没有字段时为 None）、ok（bool）、errors（字符串列表）。name/smiles 此时不校验。允许收集多条原因，不要求错误原文完全一致。
