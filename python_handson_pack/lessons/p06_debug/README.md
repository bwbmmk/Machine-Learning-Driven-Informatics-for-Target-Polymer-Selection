## 要做成什么样

例如空列表没有可计算的平均数，本题约定 `mean_or_none([])` 返回 `None`，而不是让程序除以 0。
你写的测试可以表达“我预期这个调用返回 None”。修复前失败，修复后通过。

## 打开哪里，按什么顺序写

先打开 `lessons/p06_debug/task.py`。下面每一步都可以单独当作一次小练习；不要求一次写完整关。

## 遇到这些词怎么理解

“测试”是让程序自动核对实际结果和预期结果；“复现”是用一个具体输入让问题再次出现；“回归检查”是确认修复后旧问题没有再出现。
