# 从零写小程序，一步步做出项目工具

这套流程按你现在的目标重新写：**先练 Python 基础语法，每次从空文件亲手写一个能运行的小程序；再把这些小能力接成一个处理项目数据的小工具。** 每步都有题目、输入输出例子和独立的对照代码。

原 Project 1 最终想用结构数据预测材料性质。现在先做其中最基础、确实用得上的工作：读记录、检查温度、统一单位、保存结果、按条件挑出候选。练习数据全是虚构的；做完这些也不代表已经训练了机器学习模型。

## 你今天只需要做什么

打开 [第 01 题：打印项目名](任务卡/01_打印项目名.md)，然后新建或打开 [自己的 01 程序](自己写/01_打印项目名.py)，从空白处写代码。保存后，在**本文件夹 `新流程/`**的终端运行：

```powershell
py 自己写/01_打印项目名.py
```

如果 `py` 不可用，把命令开头改成 `python`。先比较屏幕结果与题目例子；自己尝试修改一次之后，再打开 [01 对照示例](对照示例/01_打印项目名.py)。对照示例不是唯一正确写法；你的程序达到要求、能解释每行作用，就可以保留自己的版本。

## 每一题怎么做

1. 只读当前题的“要做的事”和“例子”，先口头说出输入、处理、输出。
2. 在 `自己写/` 对应的 `.py` 文件从零开始。文件里只有提醒注释，没有留待填写的函数或测试骨架；可以删掉注释，自己决定写法。
3. 运行自己的程序。看到了报错，就先解决第一处报错；能运行了，就拿例子和“自己检查”核对。
4. 再打开 `对照示例/` 的同名文件；也运行它，对比输出。写下一个你想从示例借鉴的地方，用**自己的话**改进自己的程序，再运行一次。
5. 在 [进度记录](进度.md) 写一句“我写了什么、碰到什么问题、改进了什么”。然后才做下一题。

对照时优先看三件事：**结果是否正确**、**换一个输入还能否正确**、**变量名和步骤是否容易解释**。如果你的写法更容易懂且达到要求，不必为了与示例一模一样而重写。

所有命令均从 `新流程/` 目录运行。举例：

```powershell
py 自己写/03_输入与判断.py
py 对照示例/03_输入与判断.py
```

程序等待时，按题目所说输入一个数字并回车。如果你看到 `>>>`，说明进了 Python 交互窗口；先输入 `exit()` 回到 PowerShell，再运行上面的命令。

## 路线：每个小程序都在做什么

| 小程序 | 练的 Python | 对项目积累的能力 |
|---|---|---|
| 01 打印项目名 | print、运行脚本 | 程序能启动并给出说明 |
| 02 一条资料 | 变量、字符串、数字、f 字符串 | 看懂一条材料记录 |
| 03 输入与判断 | input、float、if | 接收一个温度并检查 |
| 04 一组温度 | 列表、for、计数 | 同时处理多条温度 |
| 05 按编号找资料 | 字典、列表、循环 | 在多条记录里查找 |
| 06 温度函数 | def、参数、return | 把换算做成可复用函数 |
| 07 整理文字 | strip、upper、lower | 统一用户输入的单位和关键词 |
| 08 坏输入怎么办 | try/except、ValueError | 拒绝无法处理的温度 |
| 09 打开文件 | open、with | 从文件取到项目资料 |
| 10 读取表格 | csv.DictReader | 把 CSV 变成字典列表 |
| 11 整理记录 | 组合函数、去重 | 得到合法且单位统一的资料 |
| 12 保存结果 | json.dump、路径 | 保存整理后的结果 |
| 13 挑候选 | 筛选、排序 | 按条件列出材料编号 |
| 14 命令行使用 | argparse | 通过命令传入筛选范围 |

01–08 是基础语法区。09–14 用同一份教学表，把前面的小能力逐渐接起来。每一题都可以独立停下；需要几天完成一题都正常。E 扩展、Pandas、RDKit 和机器学习等到你熟悉这些基础后再考虑，见 [以后还能怎么扩展](后续路线.md)。

## 这里几个词先这样理解

- **材料记录**：像表格中的一行，包含编号、名字、温度。当前名字只是虚构样例。
- **Tg**：原项目关注的一种材料温度性质。做基础题时先把它当一个带单位的数字；不需要推导化学意义。
- **C / K**：摄氏度 / 开尔文；`K = C + 273.15`。
- **CSV**：表格形式的文本文件；**JSON**：能存列表和字典的文本格式。
- **筛选**：只保留符合条件的记录。这是按规则找资料，尚不是机器学习预测。
- **输入/输出例子**：告诉你程序的目标行为，不要求把示例数字直接写死来凑结果。
