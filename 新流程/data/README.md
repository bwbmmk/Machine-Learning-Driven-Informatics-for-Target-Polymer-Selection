# 练习数据

`mini_polymers.csv` 是**虚构的教学表**，共 8 行，用来练读取、错误处理和筛选。不要把它当作真实聚合物实验数据。

- `record_id`：编号。
- `name`：名字。
- `tg_value`：温度数值；有两个故意写坏的例子，一个空值，一个 `warm`。
- `tg_unit`：C（摄氏度）或 K（开尔文）。
- A02 故意重复一次，练“只保留第一次”。

按 11 题的规则清理后应有 5 条，编号依次是 A01、A02、A03、A06、A07；温度换成 K 分别是 298.15、310.0、253.15、323.15、350.0。13 题筛 300–350 K 应得到 A02、A06、A07。

不要改原文件来让程序通过。想试另一种输入，就另建一个 CSV。
