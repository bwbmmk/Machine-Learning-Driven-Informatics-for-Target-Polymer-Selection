# 01 打印项目名

**这一小块有什么用**：让你的第一个 Python 程序在屏幕上介绍这份练习。它将来可以成为项目工具的欢迎信息。

**这次练什么**：print、字符串、保存和运行 .py 文件。

## 你要自己写的程序

从空文件 [自己写/01_打印项目名.py](../自己写/01_打印项目名.py) 开始。没有输入。运行后显示两行：

```text
聚合物教学数据小工具
今天先练习 Python
```

上面只是行为例子；根据数据计算结果，不要为了得到例子把最终答案直接写死。

## 动手顺序

先自己敲一行，再运行；成功以后加第二行。试着把第二行改成“我会亲手写代码”，再运行。

运行自己的文件：

```powershell
py 自己写/01_打印项目名.py
```

如需输入数字，就在程序等待时键入数字并回车。第 14 题按上面的命令附带参数运行。

## 自己检查

是否真的出现两行？你能解释引号里的文字与 print 的作用吗？

先自己写、保存、运行，再打开 [对照示例/01_打印项目名.py](../对照示例/01_打印项目名.py)。示例是一种能运行的写法，不要求照抄。对比时问自己：我的代码哪些地方更容易读？示例处理了哪个我没想到的输入？我能用自己的话解释改动吗？改完再运行一次，并到 [进度记录](../进度.md) 写一句话。
