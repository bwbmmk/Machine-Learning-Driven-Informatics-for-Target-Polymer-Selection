# 02 一条资料

**这一小块有什么用**：把一条虚构资料拆成几个变量，然后拼成一句容易读的话。以后读表格时，每行也会有这些信息。

**这次练什么**：变量、字符串、数字、f 字符串。

## 你要自己写的程序

从空文件 [自己写/02_一条资料.py](../自己写/02_一条资料.py) 开始。没有键盘输入。请在程序里保存编号 A01、名字 sample_alpha、温度数字 25、单位 C，运行后显示：

```text
编号 A01：sample_alpha，温度 25 C
```

上面只是行为例子；根据数据计算结果，不要为了得到例子把最终答案直接写死。

## 动手顺序

先给四个变量赋值；再用 print 把它们显示为一句话。改一个数字后再运行，确认输出会跟着变化。

运行自己的文件：

```powershell
py 自己写/02_一条资料.py
```

如需输入数字，就在程序等待时键入数字并回车。第 14 题按上面的命令附带参数运行。

## 自己检查

温度是数字 25，单位是文字 "C" 吗？输出是根据变量得到的吗？

先自己写、保存、运行，再打开 [对照示例/02_一条资料.py](../对照示例/02_一条资料.py)。示例是一种能运行的写法，不要求照抄。对比时问自己：我的代码哪些地方更容易读？示例处理了哪个我没想到的输入？我能用自己的话解释改动吗？改完再运行一次，并到 [进度记录](../进度.md) 写一句话。
