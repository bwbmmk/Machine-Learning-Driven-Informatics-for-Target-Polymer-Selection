# 03 输入与判断

**这一小块有什么用**：让使用者输入一个摄氏温度。程序换算成 K，并拒绝低于或等于 -273.15 摄氏度的值。

**这次练什么**：input、float、if/else、算术。

## 你要自己写的程序

从空文件 [自己写/03_输入与判断.py](../自己写/03_输入与判断.py) 开始。输入 25 时显示第一种结果；输入 -300 时显示第二种结果。先只支持能转成数字的输入，文字错误留给 08 题。

```text
298.15 K
温度超出本题允许的范围
```

上面只是行为例子；根据数据计算结果，不要为了得到例子把最终答案直接写死。

## 动手顺序

先用 input 得到文字，再用 float 转数字。先写正常换算，再加 if 判断。第二行是另一轮运行的结果，不要求一次运行打印两个结果。

运行自己的文件：

```powershell
py 自己写/03_输入与判断.py
```

如需输入数字，就在程序等待时键入数字并回车。第 14 题按上面的命令附带参数运行。

## 自己检查

输入 0 应得到 273.15 K；输入 -273.15 应被拒绝。不要把 25 写死在换算公式里。

先自己写、保存、运行，再打开 [对照示例/03_输入与判断.py](../对照示例/03_输入与判断.py)。示例是一种能运行的写法，不要求照抄。对比时问自己：我的代码哪些地方更容易读？示例处理了哪个我没想到的输入？我能用自己的话解释改动吗？改完再运行一次，并到 [进度记录](../进度.md) 写一句话。
