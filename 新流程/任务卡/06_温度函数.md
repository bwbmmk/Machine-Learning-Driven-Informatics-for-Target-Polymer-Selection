# 06 温度函数

**这一小块有什么用**：把第三题用过的换算整理成函数，让以后很多程序都能调用它。

**这次练什么**：def、参数、return、函数调用。

## 你要自己写的程序

从空文件 [自己写/06_温度函数.py](../自己写/06_温度函数.py) 开始。程序中调用 `to_kelvin(25)` 和 `to_kelvin(-20)`，输出：

```text
298.15
253.15
```

上面只是行为例子；根据数据计算结果，不要为了得到例子把最终答案直接写死。

## 动手顺序

自己写 `to_kelvin(celsius)`；函数负责计算并返回数字，函数外的代码负责 print。换成 0 再试一次。

运行自己的文件：

```powershell
py 自己写/06_温度函数.py
```

如需输入数字，就在程序等待时键入数字并回车。第 14 题按上面的命令附带参数运行。
