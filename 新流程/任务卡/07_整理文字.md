# 07 整理文字

**这一小块有什么用**：别人可能把单位写成 ` c ` 或 `k`，也可能把名字大小写写得不同。先学会清理文字，再比较。

**这次练什么**：strip、upper、lower、in。

## 你要自己写的程序

从空文件 [自己写/07_整理文字.py](../自己写/07_整理文字.py) 开始。给单位文字 `" c "`，名字 `"Sample_Alpha"`，搜索词 `"ALPHA"`，输出：

```text
单位：C
名字包含关键词：True
```

上面只是行为例子；根据数据计算结果，不要为了得到例子把最终答案直接写死。

## 动手顺序

把单位两端空格去掉并改成大写；把名字与搜索词都改成小写，再用 in 判断。

运行自己的文件：

```powershell
py 自己写/07_整理文字.py
```

如需输入数字，就在程序等待时键入数字并回车。第 14 题按上面的命令附带参数运行。

## 自己检查

把搜索词换成 BETA，应显示 False；原始变量还在吗？

先自己写、保存、运行，再打开 [对照示例/07_整理文字.py](../对照示例/07_整理文字.py)。示例是一种能运行的写法，不要求照抄。对比时问自己：我的代码哪些地方更容易读？示例处理了哪个我没想到的输入？我能用自己的话解释改动吗？改完再运行一次，并到 [进度记录](../进度.md) 写一句话。
