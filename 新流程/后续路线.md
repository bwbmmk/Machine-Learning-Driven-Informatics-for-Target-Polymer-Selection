# 做完基础小程序后，项目还能怎么前进

现在的 01–14 题会得到一个能读取、整理并筛选教学记录的小工具。这属于原项目的**数据处理与候选筛选前置能力**。它没有使用真实实验数据，没有处理聚合物结构，也没有训练模型。

以后如果你愿意继续，按实际兴趣选下一段：

1. **继续练 Python**：把 11–14 题写过的代码分成 `读取.py`、`检查.py`、`筛选.py`，学 `import`、简单测试和调试。自己造一份新 CSV，确认程序不能只处理原样例。
2. **接触真实数据**：查清数据的来源、许可、单位、实验测量方式和缺失值含义。保存原始文件，不把虚构练习数据混进去。此时再读 [项目实施指南](../项目实施指南/00_从这里开始.md)。
3. **接触化学结构**：先学 SMILES 代表什么，再试 RDKit 读取结构并提取少量描述信息。要特别核对单体与聚合物重复单元的区别。
4. **尝试机器学习**：先用简单数值教学数据练训练/测试划分、基线和误差；之后才考虑真实 Tg 预测。每一步都要能解释输入特征与输出标签来自哪里。

这些是未来路径，不要求现在一起安装或完成。你也可以在第 08、11 或 14 题停下来，把已经会写的小程序整理成自己的作品。
