## 1 原题到底让你做什么

题目是 Machine Learning-Driven Informatics for Target Polymer Selection，可以理解为“用机器学习辅助选择满足目标性质的聚合物”。这是一个材料信息学项目：你主要负责数据、代码和评估，同时补足必要的聚合物知识。

| 原文要求 | 你的具体工作 | 能证明完成的东西 |
|---|---|---|
| End-to-end Python pipeline | 从原始数据一路运行到候选筛选 | 有顺序的脚本、配置和可重跑 Notebook |
| 实验性质与 SMILES 数据整理 | 找来源，整理结构、数值、单位、条件和引用 | 原始文件、来源登记、清洗表及排除日志 |
| RDKit 2D descriptors | 从结构计算少量可解释的数值特征 | 描述符矩阵、名称、计算失败日志 |
| Morgan fingerprints | 把局部结构编码为固定长度指纹 | 指纹矩阵、参数与结构处理说明 |
| RF、XGBoost、LightGBM 回归 | 在相同划分上公平比较三种模型 | 验证结果、最终独立测试结果、运行记录 |
| R²、RMSE | 用正确回归指标衡量预测效果 | 指标表、预测明细、真实值与预测值图 |
| Feature importance | 解释模型依赖哪些输入特征 | 重要性图及解释局限 |
| Virtual screening | 对候选库按性质约束筛选 | 全部候选预测、拒绝记录、shortlist |
| Literature benchmarks | 把预测和真实文献证据放到一起对照 | 可追溯的 benchmark 表与讨论 |
| Documented Jupyter Notebook | 把方法、代码、图表和解释组织好 | 重启内核后从头运行成功的 `.ipynb` |

原文没有规定样本量、分数门槛、工期、筛选阈值、必须做两个性质、网页或深度学习。本指南中的数量和时间均为建议。原文列出的三种模型和两种特征应在完整交付版中落实；只有 RF 的版本是中途里程碑。

## 2 推荐选题及成立条件

建议写为：“基于结构描述符和 Morgan 指纹的聚合物玻璃化转变温度预测与候选筛选”。默认仅做 Tg，以 K 为内部单位，在报告中可附 °C；转换为 `Tg_K = Tg_C + 273.15`。

优先 Tg 是为了控制初学者工作量，并利用已经找到的公开数据线索。弹性模量可作为第二阶段：它还需要区分 Young's modulus、储能模量等定义，并控制温度、应变速率、结晶度等因素，不宜把不同测量口径直接合并。

**输入方案有两条路线，必须选定一条：**

- A，严格单体路线：用确实配对到目标聚合物的单体结构。先限于一个聚合反应类型和一类较简单的均聚物；记录单体到聚合物的对应证据。若两个或更多单体共同决定材料，不得随便只保留其中一个。
- B，重复单元路线：使用带连接点的重复单元 SMILES，直接研究重复单元到 Tg 的关系。这通常更接近公开聚合物结构数据的表示，但改变了原题字面输入，需要老师确认。候选库也必须采用同样表示。

乙烯的单体可写作 `C=C`，聚乙烯的一个重复单元可写作 `[*]CC[*]`。前者的双键在聚合时发生变化，后者的 `*` 表示与相邻单元连接的位置。这个例子只解释结构表示，不包含任何性质数据。不能用“删除星号”或“把所有双键改为单键”作为通用聚合反应算法。

SMILES 只编码选定的结构信息。聚合物实际 Tg 还受分子量、立构、组成、测试方法等影响。因此这个模型是在数据所覆盖条件下做近似预测，不是由一个字符串唯一确定任何材料的全部性质。

## 4 三个完成层次

| 层次 | 范围 | 能说什么 |
|---|---|---|
| 调试闭环 | 约 20–50 条真实记录或明确标注的教学数据、RF、预测 CSV | 程序流程能够执行，不能声称可靠预测 |
| 完整课程版 | 经审计的真实数据、两类特征、三种模型、分组评估、候选和文献对照 | 在明确数据与适用范围下完成题目要求 |
| 扩展研究版 | 家族/结构簇外推、校准不确定性、学习曲线、第二性质 | 需要额外数据和评估，不是默认起点 |

争取数百到数千条可用且有多样性的独立聚合物记录，但没有一个固定数字能保证可靠。1000 次测量来自 20 种聚合物，也不能当成 1000 个独立结构。若只有几十种材料，应将工作定位为方法演示并缩小结论；若清洗后数量大幅减少，要透明报告。

## 5 阶段门槛

1. **范围门槛**：目标、表示、单位、数据来源候选和待确认问题写入 `docs/project_brief.md`。
2. **数据门槛**：至少抽查 20 条记录，能追到来源、确认是目标聚合物的实验 Tg；看清单位与表示才进入正式建模。
3. **闭环门槛**：真实数据经过清洗、特征、RF，能够输出预测明细；不用追求漂亮分数。
4. **评估门槛**：三种模型和预处理在训练数据内部选择，测试集未参与决策，重复结构不跨集合。
5. **筛选门槛**：候选与训练表示一致、去除已知重复、能标记范围外预测，并有文献证据矩阵。
6. **交付门槛**：从干净内核重跑，表图与实际结果一致，引用可追溯，结论不越界。

## 6 结果不好时怎么处理

先查单位、标签含义、结构对应、重复和划分，再看数据量、性质噪声、特征，最后才调整参数。不要反复更换随机种子直到出现最高 R²，也不要删除“难预测”的测试样本。若模型不优于 Dummy，要报告原因并把筛选表标为探索性，不能宣称模型已具备可靠筛选能力。

项目可以在“模型效果有限，但方法正确且限制清楚”的状态下形成诚实的课程成果；科学有效性仍需证据，不能由“代码没有报错”代替。
