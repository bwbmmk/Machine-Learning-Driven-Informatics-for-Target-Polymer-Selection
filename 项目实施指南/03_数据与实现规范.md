## 1 实现原则

先只做一个目标 `tg_k`，一套确认过的输入表示，一个能追溯的数据集。用脚本承担数据处理和训练，Notebook 调用这些函数并解释结果，避免两套代码计算同一个结果。先跑小样本，再跑全量；固定随机种子，例如 42，并记录软件版本、数据哈希和配置。

RF 来自 scikit-learn；XGBoost 和 LightGBM 是独立库，通过兼容 scikit-learn 的接口使用，不是 scikit-learn 自带的两个模型。相关官方接口入口见 `05`。

## 4 数据字段

### 4.1 原始来源登记 data/sources.csv

至少包含：`source_id, title, url, doi, accessed_at, file_name, sha256, license_or_terms, access_status, notes`。找不到 DOI 可空，网址或稳定出处至少一个有效；权限不明确时写 `unclear`，不能自行推断允许重新发布。

### 4.2 建模表 data/processed/polymer_tg.csv

| 字段 | 含义与约束 |
|---|---|
| record_id | 唯一字符串 ID，不随排序变化 |
| polymer_id | 同一种聚合物的稳定 ID，人工或可靠来源核对 |
| polymer_name | 原始名称，可未知，不能靠名称直接充当模型特征 |
| smiles_raw | 原始结构字符串，永不覆盖 |
| smiles_model | 按统一规则处理的实际模型输入 |
| representation | `monomer` 或 `repeat_unit`；同一个模型不混用 |
| mapping_evidence | 单体到聚合物对应证据或重复单元表示依据 |
| structure_key | 规范化结构键；注意普通 canonical SMILES 不能解决所有聚合物等价表示 |
| group_id | 用于划分的聚合物身份组；包含等价结构和重复测量 |
| tg_raw / tg_unit_raw | 原始数值与原始单位，单位来源可追溯 |
| tg_k | 统一到 K 的有限数值；唯一目标列 |
| label_type | `experimental`、`simulation`、`prediction`、`unknown` |
| source_id / source_locator | 对应来源及原表、页码、行号或数据库记录 ID |
| measurement_method | DSC、DMA 等，原文未提供则 `unknown` |
| molecular_weight / molecular_weight_unit | 若有则记录，并注明 Mn/Mw 等类型；无则留空 |
| conditions / polymer_family | 条件与材料类别，可未知，不能无依据补齐 |
| n_measurements / tg_spread_k | 若汇总重复实验，记录次数和离散程度 |
| quality_flag / notes | 冲突、未知条件、映射不确定等说明 |

正式训练必须有可靠 `smiles_model`、`group_id`、`tg_k`、实验标签身份和来源。没有数均分子量不一定整行删除，但要保留缺失和限制。缺单位、实验身份不明或结构映射无法确认的记录先隔离，不靠猜测补全。

### 4.3 候选表 data/candidates/candidates.csv

至少有 `candidate_id, smiles_raw, smiles_model, representation, candidate_source, mapping_evidence, notes`，**不要求有 Tg 标签**。如来自已知材料且有文献数值，单独放 benchmark 表，用于对照，不放进候选输入特征。

### 4.4 文献表 data/benchmark/literature.csv

建议有 `benchmark_id, candidate_id, polymer_id, structure, representation, literature_tg_raw, literature_unit, literature_tg_k, measurement_method, conditions, doi_or_url, locator, evidence_type, comparable, overlap_status, reason`。`evidence_type` 区分“同一材料实测”“相近材料参照”“仅计算结果”。只有前者且条件可比、与训练来源无重叠时，才能支持较强的外部验证说法。

## 5 清洗规则

1. 保存原始文件及哈希，记录下载或人工抽取步骤，不能直接覆盖原表。
2. 检查列含义、数值类型、空值、来源和实验身份；机器预测标签单独存放。
3. 单位按来源转换。不能凭“数值看起来像 K”自动猜单位；未知单位先隔离。
4. 用 RDKit 解析并检查价态等；失败记 `parse_failed`，不要悄悄删掉再重排标签。
5. 区分重复行、同结构重复实验、名称相同但材料不同、同聚合物不同 SMILES。
6. 完全重复的同一测量可去重。相同材料在可比条件下多次实验，可按事先规定的中位数等规则汇总；不可比条件保留并标记或按范围排除。不要为提高分数选择某个 Tg。
7. 极端值先查来源和单位。不能按全表分位数机械删除真实高 Tg 材料，也不能用模型残差删测试点。
8. 共聚物、混合物、交联体系、立构不明等若不在本项目范围，按明确理由排除并统计。
9. 清洗日志写出每一步输入数、保留数、排除数及 ID。隔离、聚合、重复删除分别统计，保证能解释数量变化。

抽查至少 20 条，额外查看所有明显异常类别。这个数是起步审计量，不代表 20 条抽查即可保证整份数据可靠。

## 6 结构与特征规范

先冻结 `representation_policy.md`。重复单元中的 `*` 可能影响描述符含义与计算，RDKit 能解析不等于描述符一定有物理意义。对小样本明确测试：采用保留连接点的图，还是经化学核对的封端片段；记录可用描述符清单、失败比例和每一项含义。不得简单替换字符串、静默失败或把封端片段当成实际聚合物。

普通 canonical SMILES 只规范分子图；不同重复单元起点、重复单元倍长等可能仍表示同一聚合物，需结合可靠聚合物 ID、等价表示审计或专门工具处理。不要假称普通 RDKit 已完全解决聚合物规范化。

起步用固定清单的约 10–20 个 2D 描述符，例如环数、芳香环数、氢键供受体数、TPSA、可旋转键数、重原子数，以及语义核对后的片段 MolWt/MolLogP。片段 MolWt 不能用来代替整条聚合物链的 Mn/Mw。描述符失败产生缺失和日志；仅训练折内拟合缺失值处理，不能拿全表均值填补。

Morgan 起步参数建议：`radius=2, fpSize=2048`，使用 `rdFingerprintGenerator.GetMorganGenerator`；手性开关、位/计数类型明确记录。它是圆形邻域指纹，不要误写成 RDKit 的路径指纹或拓扑扭转指纹。参数是起点，不是题目规定或最优保证。

必须检查：ID 与标签一一对齐；特征长度稳定；相同输入可复现；指纹无异常值；描述符全空列/常量列处理规则只在训练内部确定。可确定且不依赖全体数据统计的逐分子特征计算可在切分前缓存；插补、缩放、特征筛选必须在训练折内拟合。树模型起步不需要标准化。

实验至少包含三模型 × 两种特征，共六个基础组合。`descriptors + Morgan` 拼接可作为第七类扩展实验，不必作为第一版必做项。描述符和指纹结果分开呈现，有助于解释表示方式的影响。

## 7 划分与模型选择

推荐主评估：按 `group_id` 保留约 20% 组为最终测试，其余约 80% 为开发训练集；组大小不同时样本比例不会恰好 80/20。开发集内部做 5 折 GroupKFold，组数不足则降低折数并说明。所有模型共用 `artifacts/splits.csv`；需要记录 `record_id, group_id, split, cv_fold`，测试行的 `cv_fold` 为空。

先分组再分配；结构身份核对是防止泄漏的必要步骤，不是偷看测试标签。禁止测试集参与：超参数选择、early stopping、插补、特征选择、阈值调整和根据测试结果挑最终模型。相关通用原则见 [scikit-learn 官方常见陷阱](https://scikit-learn.org/stable/common_pitfalls.html)。

建议流程：

1. `DummyRegressor(strategy="mean")` 给出最低参照。
2. RF、XGBoost、LightGBM 先用保守配置跑通。
3. 只在开发集内验证，主选择指标定为平均 RMSE，越低越好；R²、MAE 辅助报告。
4. 粗搜索建议每种模型 10–20 组配置以内，先小样本估时；控制总线程，避免外层 CV 和模型内层都占满 CPU。
5. RF 关注 `n_estimators,max_depth,min_samples_leaf,max_features`；XGBoost 关注 `n_estimators,max_depth,learning_rate,subsample,colsample_bytree`；LightGBM 关注 `n_estimators,num_leaves,min_child_samples,learning_rate`。先只调 2–3 个关键项。
6. 新手先不加 early stopping，减少验证集使用错误；若加入，每折只用训练内部子集，绝不能传入最终测试集。
7. 按预定 CV 指标选出最终模型、特征和参数，在完整开发集重训后，只做一次正式最终测试。

六个组合的 CV 表体现公平比较；最终模型测试表单独输出。如课程需要三模型测试比较，应提前冻结每个模型的配置，一次性报告，仍不得根据测试表重新挑参。

分组划分只能减少同材料泄漏，不能证明能外推到陌生化学家族。可选增加家族/指纹簇留出作为更难评估，先验证分组规模；不能直接照搬小分子 scaffold split 并假定线性聚合物都有有效 scaffold。随机按行划分只能作有明确局限的补充对照。

## 8 指标、解释和模型保存

- 保存 CV 每折和平均±标准差，不把折间标准差称作统计置信区间。
- 最终测试保存每一行真实/预测值、残差、结构组和来源。RMSE、MAE 单位为 K，R² 无单位；温差的 K 与 °C 数值相同，绝对温度不同。
- 图至少包括：目标分布、真实对预测及 y=x 线、残差图、CV 模型比较图、特征重要性图。
- 先在开发集留出的验证折做 permutation importance，不根据测试重要性再改模型。只解释模型关联，不能写成化学因果证明。
- Morgan 某一位可能对应多个局部结构，不可把 `bit_123` 直接当成唯一官能团。优先解释描述符模型；若最佳是指纹模型，说明解释对象差异，并给出指纹重要性及映射限制。
- 保存模型和预处理整体、特征列顺序、RDKit 参数、结构策略、训练 ID、数据哈希、单位和依赖版本。只加载自己生成或来源可信的 joblib/pickle。
- 加载后的预测应与保存前在固定样本上相同或在预定小数容差内，错误输入应得到可读的失败原因。

课程版可直接使用开发集训练、经独立测试验证的模型筛选。若最后用全量有标签数据重训“部署模型”，另存版本，不再将其在原测试集的得分作为独立测试成绩。

## 9 虚拟筛选与适用范围

先做约 100–1000 个有来源、表示统一的候选；这是建议批量，实际依据数据可得性。候选要与训练、测试及其等价聚合物身份核对，已知记录另列为回顾性对照，不冒充新发现。

筛选目标必须在正式筛选前写入配置：如 `tg_min_k` 或 `tg_min_k/tg_max_k`。可用 150 °C = 423.15 K 演示阈值换算，但**这不是自动采用的项目指标**。应根据应用要求、开发集标签范围和老师意见确定；没有需求时明确写“演示约束”，不宣称工业可用。

起步适用范围方法：计算每个候选与训练指纹的最大 Tanimoto 相似度，同时检查关键描述符是否超训练范围。相似度只作经验性风险提示；不默认 0.7 或 0.8 是通用可靠边界。可用开发集交叉验证中的误差—相似度关系制定阈值，样本不足时只报告连续值，不硬做可信/不可信分类。

各树或多个模型预测的标准差是分歧指标，不是已校准的 95% 置信区间。校准预测区间作为扩展任务；若采用 conformal 等方法，需要额外校准数据及适用假设说明。

候选矩阵建议字段：`candidate_id, smiles_model, representation, predicted_tg_k, predicted_tg_c, meets_constraint, max_train_similarity, nearest_train_id, descriptor_range_flag, model_disagreement_k, domain_status, rank, literature_tg_k, literature_source, benchmark_relation, verification_status, selection_reason`。不计算的指标留空并解释；不要用 0 代替未知。

保留全量预测和拒绝原因，再输出 Top 10–20 供人工核查。若没有候选满足条件，输出空 shortlist 和原因；不能偷偷降低阈值。必要时另列“约束外最接近候选”，明确与合格集合区别。

## 10 文献对照怎么完成

最容易遗漏的是“候选 matrix evaluated against literature benchmarks”。单纯预测 Top 10 不够。

建议建立 5–10 个有文献实测 Tg 的对照材料，先检查它们是否已出现在训练源中。最好在模型冻结前锁定独立 benchmark 集，并隔离不参与训练和选参。每个对照都有结构、实验值、单位、条件、DOI/网址及表/页位置。

对同一材料、可比条件、未污染的 benchmark 可算外部 MAE/RMSE；对结构相近或条件不同的文献只能做定性参照，不能硬算“该候选预测误差”。没有文献的新候选可以进入 shortlist，但必须注明待实验验证，并与已知 benchmark 分开呈现。新颖性和可合成性不能仅由模型给出。

## 11 少量关键检查

后续代码至少验证：无效 SMILES 不返回貌似正常的预测；°C 转 K 正确；ID 不串行；同组不跨训练/测试或 CV 折；标签/来源等非特征列不进入 X；训练和筛选特征一致；保存/加载预测一致；没有候选时正常输出空表。

不需要初学阶段追求覆盖率数字。用这些检查保护最容易影响科学结论的边界，最后从新内核重跑整条流程。
