## 共同约定

练习工作目录是 python_practice。最初只用 JSON 原始数据和几个 .py 文件；到 P07 才拆模块。

输入为 data/teaching_records.json：一个含 12 个字典的列表。字段包括 record_id、name、smiles、tg_value、tg_unit、is_synthetic。所有数值是人为教学值，结构字符串与名称不建立真实材料对应关系。

本练习的校验规则：

- 每条必须是字典，record_id 是非空字符串。
- tg_value 必须可转换为有限浮点数；空白、null、布尔值、NaN、Infinity 不接受。
- tg_unit 只接受 C、K（先去两端空格并转大写）。
- 转换结果必须严格大于 0 K。这里只练格式和基础数值边界，不判断真实聚合物的合理 Tg 范围。
- name 和 smiles 暂不参与剔除；SMILES 的化学合法性留给 E02。
- 不修改原始字典，输出新字典，增加 tg_k 并保留原值及 is_synthetic。
- 去重按通过校验后的 record_id：相同内容重复仅保留第一条；同 ID 内容冲突时保留第一条、把后续条标为 duplicate_conflict，明确这只是教学规则。科研数据要重新设计身份和重复测量规则。
- 每次运行输出到独立目录；不能覆盖输入。输出逐行带状态与原因，必要时记录从 1 开始的原始行序号，区分重复 ID。

## P01 读取并查看文件

**要写**：完成现有 01_read_records.py 的 load_records(path) 和 main()。
**输入/输出**：读教学 JSON；输出总条数，以及前 3 条的 record_id、name、tg_value、tg_unit。
**知识**：pathlib、json.load、列表和字典、函数返回值。
**验收**：输出 12 条；前三个 ID 为 EX01、EX02、EX03；能解释读取结果是什么类型。
**独立变式**：把“前 3 条”改为由函数参数控制的前 N 条，N 大于记录数也正常。
**此时不做**：清洗、异常恢复、安装第三方库。

## P02 查询记录

**依赖**：P01。
**要写**：find_by_id(records, record_id) 返回所有匹配项；search_by_name(records, keyword) 支持不区分大小写的子串匹配，空关键词返回空列表。
**输出**：终端打印匹配结果和数量；无匹配时显示清楚的提示。
**知识**：循环、条件、字符串方法、把计算与显示分开。
**验收**：查询 EX02 得到 2 条；查不存在的 ID 得到空列表；不能只返回第一条而掩盖重复。
**独立变式**：查询结果只显示用户选择的两个字段。
**思考**：数据增大后每次从头遍历有什么成本？此时能说清即可，不必立即优化。

## P03 单位转换函数

**依赖**：P01。
**要写**：to_kelvin(value, unit) 返回浮点数；错误输入抛带明确信息的 ValueError；不在函数里 print。
**知识**：float、字符串规范化、math.isfinite、异常、单位转换。
**验收**：25 C → 298.15 K；310 K → 310 K；-20 C → 253.15 K；0 C 合法；0 K 不合法；未知单位和非数字不接受。
**独立变式**：写 kelvin_to_celsius，并用往返转换检查结果，浮点比较用容差。
**范围**：只覆盖共同约定列出的类型，不做适配任何 Python 对象的通用转换器。

## P04 批量校验与错误解释

**依赖**：P03。
**要写**：validate_record(record) 返回一个错误原因列表；check_records(records) 逐行记录结果，能够继续处理后面的记录。
**知识**：函数组合、列表收集、局部异常处理、enumerate。
**输出**：按原始行序号、ID、通过/失败、原因打印报告。
**验收**：本数据校验通过 7 行、失败 5 行；此时还不去重。失败的是 EX04–EX08。EX09 的错误结构字符串在这一步不应被当作已通过化学验证。
**独立变式**：构造一条缺 record_id 且温度也错误的记录，收集两个原因。
**避免**：一个宽泛 except 把代码错误全部变成“坏数据”。

到这里即可结束阶段 A：你已有一个能读文件、查询、校验和转换的小程序。

## P05 清洗、去重并导出

**依赖**：P04。
**要写**：clean_records(records) 返回清洗记录和逐行处理日志；写 save_csv、save_json。输入、校验、去重与输出各自分开。
**输出**：output 下的 cleaned.csv、cleaned.json、rejected.csv、summary.json；目录不存在时创建。保留原始字段，增加 tg_k 和处理状态需要的字段。
**知识**：csv.DictWriter、json.dump、字典复制、set/dict、文件编码。
**验收**：12 行输入 = 6 行保留 + 5 行校验失败 + 1 行重复。输出顺序约定为原输入顺序；重新读取输出后数量与类型合理；原始输入文件未改变。
**独立变式**：添加同 ID 不同温度的教学记录，后来的记录单独记为 duplicate_conflict，不能静默覆盖。
**说明**：CSV 读回来的数值往往是字符串，比较前要明确类型转换。

## P06 练习定位错误和回归检查

**依赖**：P05。
**要写**：用标准库 unittest（或早期几个 assert）检查转换、校验、重复和空输入；先从能手算的三个例子开始，再增加失败输入。
**知识**：阅读 traceback、最小复现、断点、临时文件。
**输出**：check_behavior.py 或 tests/test_processing.py，以及三条错误复盘记录。
**验收**：在代码副本中把 273.15 故意写错，检查能发现错误；恢复正确后通过；验证空列表输入与错误 JSON 文件的行为，不把它们混为一类问题。
**独立变式**：给现有函数补一个之前漏掉的边界检查，并说明为何值得保留。
**范围**：学习关键行为验证，不追求测试数量或覆盖率百分比。

## P07 整理函数和模块

**依赖**：P06。
**要写**：把重复功能整理进最多 3 个模块，例如 io_utils.py、processing.py、main.py。源代码中不必创建复杂包结构。
**知识**：import、main 入口、职责划分、函数命名、docstring。
**验收**：import 模块不自动生成文件；重构前后清洗结果相同；能够画出 main 调用了哪些函数；此前检查仍通过。
**独立变式**：给另一个小脚本复用单位转换函数，无需复制代码。

## P08 做成命令行工具

**依赖**：P07。
**要写**：用 argparse 添加 --input、--output-dir；让路径由参数指定；处理文件不存在、JSON 格式错误、输入根对象不是列表等情况。
**目标命令**（在项目根目录；此程序将在本题实现）：

~~~powershell
py python_practice/main.py --input python_practice/data/teaching_records.json --output-dir python_practice/output/run01
~~~

**验收**：--help 有说明；正常输入成功；无法处理的输入给清晰错误并返回非零状态；输出路径不能指向输入文件。已有输出文件时明确拒绝或要求显式覆盖参数，行为写进说明。
**独立变式**：增加 --preview 参数，只报告处理结果而不写输出文件。
**区分**：文件级错误导致运行失败；个别脏行按规则排除，剩余行可正常处理，结果里报告失败行数。

到这里即可结束阶段 B：你已有一个可以重复使用的命令行清洗工具。

## P09 筛选、排序与统计

**依赖**：P05，推荐接在 P08 后。
**要写**：按 tg_k 的闭区间筛选，按温度排序并取前 N 条，计算数量、最小值、最大值、均值。从清洗结果读入，不另抄数据。
**知识**：sorted/key、statistics、空列表、边界条件。
**验收**：教学清洗表共 6 行；筛选 300–350 K 得 3 行（310、323.15、350）；空结果不除以零，摘要值可用 null；最低值大于最高值或 N 为负时拒绝。
**独立变式**：升序改降序；再增加中位数并手工核对一次。
**输出**：filtered.csv、stats.json，明确这是教学筛选，不是机器学习预测。
