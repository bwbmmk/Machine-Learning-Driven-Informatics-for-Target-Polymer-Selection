## 1 先核查哪条数据路线

建议 T05 先调查下面 A 与 B，拿少量记录做真实可行性检查后再决定。不要一开始同时拼接多个来源；它们可能互相转录同一批文献，造成重复甚至训练/benchmark 污染。

### A 有论文关联的 Tg 表格

[PolymerTg 作者公开仓库](https://github.com/PolymerTg/Polymer-Tg-Machine-Learning) 页面可访问，列有 `Polymer Tg SMILES.xlsx`。关联研究为 [Prediction of Glass Transition Temperature of Polymers Using Simple Machine Learning](https://pmc.ncbi.nlm.nih.gov/articles/PMC11398084/)。论文搜索内容给出了该仓库的数据可用性线索；本次进一步打开全文时遇到访问验证，因此尚未完整审阅全文或表格。

下一步：实际下载表格，对照原论文检查标签单位、结构语义、实验来源、重复和使用许可，再决定是否选为主数据源。不能因文件名有 SMILES 和 Tg 就认定它已满足原题。仓库页面未看到明确的许可说明，应继续核查，不把文章开放许可自动套用到所有数据文件。

### B 明确区分实验与计算记录的公开研究

[Automated BigSMILES conversion workflow and dataset for homopolymeric macromolecules](https://www.nature.com/articles/s41597-024-03212-4) 的 Data acquisition 说明，在其汇集的带 Tg 记录中，有 304 条来自实验来源，另有 662 条为机器计算来源。这说明下载整表后必须区分标签性质，不能把全部 Tg 都当实验测量。

下一步：沿文章 Data Records / Data availability 找原始 SMILES 和实验子集，检查修订说明、单位、许可及来源。这个入口是小规模方法验证的备选，不是保证最终恰有 304 条合格独立聚合物，也不要求你学习或实现 BigSMILES 转换算法。

### C 后续补充线索

[Machine learning analysis of a large set of homopolymers to predict glass transition temperatures](https://doi.org/10.1038/s42004-024-01305-0) 报告了从公开来源汇集的均聚物 Tg 数据，可继续检查其补充材料与数据可得性。先确认其结构表示和目标变换；不能照抄论文分数来当本项目门槛。

[Curated Glass Transition Temperature for Polymers 的 Zenodo 记录入口](https://zenodo.org/records/15789599) 可作为待检查线索，但本次未能通过网页工具直接读取该记录，未确认文件内容和原始使用条款。它不是本计划已验证可用的主来源。

## 2 原题里的三个名字怎么处理

| 原题入口 | 本次核查状态 | 在你的项目中如何使用 |
|---|---|---|
| Polymer Genome | 官网明确说明是使用预训练模型预测聚合物性质的平台，并接收重复单元结构 | 可作领域工具参考；其预测不能当实验标签；不能假设可下载完整实验训练集 |
| PoPE | 未可靠确认与题目对应的官方入口 | 请老师给准确网址或论文；不要擅自改成 PoLyInfo |
| PubChem | 官方提供 PUG REST 程序化查询说明 | 可核查单体身份与结构；聚合物实验 Tg 与单体的配对需其他证据 |

依据：[Polymer Genome 官网](https://www.polymergenome.org/)、[PubChem PUG REST 官方教程](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest-tutorial)。这里建议将 PubChem 用于结构核查，是针对本项目的范围判断，不是声称 PubChem 完全不包含任何聚合物相关信息。

如果使用 PubChem API，遵守官方当前请求频率限制、使用批量查询与缓存，并记录结果的 CID 和查询日期。名称查询可能有歧义，不能“查到第一个 CID 就默认正确”。不需要为了做课程项目从零写大规模爬虫。

PoLyInfo 是另一个需要单独核查访问条件的入口。其 [官方性质预测帮助](https://polymer.nims.go.jp/PoLyInfo/guide/en/Property_Prediction_HELP_EN.html) 也含计算预测功能，因此看到 Tg 值仍要核对是实测记录还是预测输出。

## 3 候选结构库和训练集不是一回事

[PI1M 作者仓库](https://github.com/RUIMINMA1996/PI1M) 提供约百万规模的生成聚合物结构，采用 p-SMILES，并标注学术用途。可以在重复单元路线获准、许可和格式核查完成后，考虑抽取很小的一部分做候选结构库；不要一开始下载处理全库。

它不是“百万条实验 Tg 数据”，也不是可直接当单体库使用的表。结构由生成方法得到，不意味着可合成；若输入路线严格要求单体，应寻找或构建有可靠映射的单体候选，不能把 p-SMILES 改列名就交付。

更简单的候选来源是经文献和反应范围核实的一小组结构。数量少但来源、映射和适用性清晰，通常比无依据生成成千上万个字符串更有价值。

## 5 读一篇论文的最小方法

第一次按这个顺序：摘要 → 数据来源/可得性 → 方法里的结构表示和标签单位 → 划分方法 → 结果图 → 局限。不要第一次从第一句逐字读到最后。

给每篇相关论文做一页笔记：研究什么性质；多少独立聚合物；结构是什么；实验还是模拟；怎么划分；评价在哪个尺度/单位；是否有可下载数据；哪些局限与自己相关。特别留意论文是否对 Tg 取对数、归一化或用了不同单位；不能把不同尺度的 RMSE 直接比较。

引用记录至少保留题目、作者、年份、DOI/稳定链接、数据在何处和访问日期。AI 可以辅助提取，但你需要核对原文和数字。报告中的每一个文献 Tg 都应能追到具体证据，不靠模型记忆。
